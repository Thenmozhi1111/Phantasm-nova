# Events 3D Models

These are the GLB assets used by the Events 3D scene.

The source configuration expects these paths:
- ancient-stone-gate.glb
- ancient-tree.glb
- minecart.glb
- moon.glb
- railway.glb
- stone-pathway.glb
- ruined-towers.glb
- old_ruined_temple.glb

Mobile performance mode deliberately avoids loading the heavy Ancient Gate and scenery GLBs where possible.
