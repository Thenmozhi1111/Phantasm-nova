# Phantasm CSE Symposium — React UI

A futuristic, responsive authentication UI built with the requested stack:

- React 19
- Vite 7
- Tailwind CSS 4
- React Router 7
- Three.js
- React Three Fiber
- Drei
- GSAP

## Visual upgrades

- Interactive 3D energy-core / torus-knot centerpiece
- Holographic rotating rings and particle field
- Pointer-reactive 3D scene
- Glassmorphism card with desktop tilt effect
- Circuit-board/grid overlays and animated scanline
- Neon lighting and ambient glow layers
- Responsive mobile/tablet/desktop layout
- Reduced-motion fallback

## Run

```bash
npm install
npm run dev
```

Then open the local Vite URL shown in the terminal.

Routes:

- `/login`
- `/register`
